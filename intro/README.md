# Intro: Strudel foundations

Theory classes to read before (or alongside) the hands-on folders:

- `patterns/` works on rhythm, harmony and effects with built-in sounds.
- `clips/` works with your own audio samples.

Each class ends with a **Practice** section that points to the exercises in
those folders, so you can try each idea as soon as you've read about it.

| # | Class | What you'll understand |
|---|---|---|
| 01 | [Roots, history and present](01-roots-history-and-present.md) | Where Strudel comes from: computer music, algorithmic composition, live coding, TidalCycles, and what's happening now |
| 02 | [Patterns, cycles and time](02-patterns-cycles-and-time.md) | The core idea: a pattern is a function of time. Cycles, events ("haps"), tempo, and how the scheduler turns code into sound |
| 03 | [Mini-notation](03-mini-notation.md) | The small rhythm language inside the quotes, symbol by symbol |
| 04 | [Sound: samples and synthesis](04-sound-samples-and-synthesis.md) | Where sound comes from (samples, synths, soundfonts) and the order effects are applied in |
| 05 | [Transforming patterns](05-transforming-patterns.md) | Building music from transformations: chaining, layering, functions that take functions, signals and randomness |
| 06 | [Live coding practice](06-live-coding-practice.md) | Performing, practising, sharing, collaborating, and the culture around it |

## How to read them

1. Read 01 once to see the big picture. It explains *why* Strudel works the way it does.
2. Read 02 and 03 carefully. Everything else builds on them.
3. Keep 04 and 05 open as references while you work through `patterns/` and `clips/`.
4. Read 06 when you start playing for other people, or with them.

> These notes were written in November 2026. Strudel moves quickly, so for
> function details, check the official docs at <https://strudel.cc/learn>.
